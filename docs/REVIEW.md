# 审查运行方式

在仓库根目录执行：

```powershell
.\code\.venv\Scripts\python.exe .\code\demo.py
```

演示账号：demo_admin（管理员）、demo_seller（卖家）、demo_buyer（买家）、demo_other（另一位买家）。共同演示密码：DemoPass123!

演示目录为 code/data/demo_gallery，与之前的账号和商品分开。图片由用户提供，价格、成色和描述为教学样例设定。演示数据库不随提交包打包，运行时自动生成。

建议检查顺序：

1. 买家登录，筛选商品、查看图片和详情，发起预约；重复点击仍为原预约。
2. 卖家登录，在卖家预约中确认；登记实际交付后，买家再确认完成。
3. 卖家新建带图片商品，检查必填项、成色、运费、议价、Enter和Ctrl+Enter；保存草稿或提交审核。
4. 管理员审核通过或驳回；再回到买家检查商品是否公开。
5. 多人预约、双方取消、拒绝取消转争议、违规和账号禁用；检查状态与消息。
6. 管理员审计导出、备份以及恢复验证；普通用户不得进入后台。

使用原来的数据：

```powershell
.\code\.venv\Scripts\python.exe .\code\main.py
```

旧空草稿仍保留，可编辑补全或删除；提交审核会拒绝缺项。不要为了清理旧草稿删除整个数据库。

完整回归与构建：

```powershell
.\build.ps1
```

恢复备份到新目录（禁止覆盖已有目录）：

```powershell
.\code\.venv\Scripts\python.exe .\code\manage.py restore-backup '备份文件.zip' '全新恢复目录'
.\code\.venv\Scripts\python.exe .\code\main.py --data-dir '全新恢复目录'
```

Git：本次改动将在本地开发分支保存为可审查提交。审查与修改后再决定推送；git status、git diff、git log可以核对实际状态。

本包是审查版源码，未包含学生独立完成的实验报告，不是最终实验提交包。

新版演示图库位于 `code/data/demo_gallery`：15件带图可浏览商品、1件带图待审核商品、1件带图草稿。旧的 `code/data/demo` 目录保留，不清空已有演示交易。分类采用已确认的10类，启动时迁移旧分类。

商品详情在当前主界面内打开，返回时保留列表筛选和页码。可点击缩略图、上一张/下一张或左右方向键切换图片，Esc返回；长描述支持滚动。7件样例增加详情图，新建演示库共29条图片关联（含待审核和草稿的封面复用）。已有有效预约、非已发布状态或超过5张上限的样例暂缓补图，解除限制后再次启动demo.py会重试，不清空交易数据。

卖家主页：点击商品详情中的卖家框或“进入卖家主页”，可查看公开资料、在售商品和累计成交率。个人主页可编辑昵称/简介/自填所在地；IP属地未获取。商品详情点击“私信卖家 / 咨询商品”进入独立聊天页，Enter换行、Ctrl+Enter发送；在消息中心的“私信会话”查看与回复，点击刷新获取新消息。测试时先买家发送，再退出并登录卖家查看回复；双方必须运行同一数据目录。当前没有跨电脑网络收发功能。

头像：商品详情的卖家框和用户主页均显示头像。个人主页→编辑我的公开资料→更换头像，可选择本地JPEG/PNG图片。没有上传头像时使用内置默认头像，原图损坏或丢失也会回退默认图。

私信以气泡显示：我方右侧绿色，对方左侧白色；发送后显示正文并滚动到最新消息。支持头像、时间、长文字换行和加载更早记录；对方新回复可点击“刷新最新消息”读取。已有私信保留。

卖家主页与私信独立：卖家框→公开资料和在售商品；商品详情“私信卖家 / 咨询商品”→独立气泡聊天页，仅显示对方、咨询商品名称与对话。两者均可返回原商品详情。

预约操作：在“我的预约”或“卖家预约”上方按预约状态查看，再选中一条记录；界面只显示该记录当前可用的操作。取消申请发起方显示等待提示，对方显示同意/转人工；已完成或已结束记录仅查看详情。分类旁显示数量，刷新后保留分类；暂无记录可切换其他分类或全部预约。

消息中心：系统通知点击“查看消息”或双击行，在页内显示正文；红点表示仍有未读，读后移除。“全部已读”同时清除当前账号收到的系统通知和私信红点，不删消息。私信仅在对方阅读或主动设为已读后，在我最新发出的一条气泡下显示“已读”；未读不显示文字，发送新消息后隐藏回执。聊天页会自动检查回执，对方新回复仍可用刷新读取。

新版排版：顶部为无框文字导航，选中入口显示橙色下划线；导航名称与功能不变。我的商品、我的预约、卖家预约使用横向商品卡片，包含缩略图、价格、状态及对应行内操作，可滚动查看。我的商品可按商品状态筛选；预约卡片展示预约当时的图片和价格快照。点击卡片按钮直接作用于该条记录，仍受原有角色、状态和预约限制校验。

预约分类已简化为横向“全部、待确认、交易中、取消 / 争议、已完成、已关闭”，各类显示数量。交易中的卡片仍标明待收货/待交付/待确认完成，取消争议仍区分待我处理、等待对方回复和管理员处理中；具体可用操作不因合并分类而改变。

预约详情：点击卡片“预约详情 / 快照”，在当前主界面打开分区详情页，不弹窗。可切换预约时图片，查看商品描述、价格、实际交易进度和授权电话、处理说明；长内容向下滚动。返回保留原预约分类及选择，“刷新详情”重新获取当前状态和电话权限。

主消息中心已改为会话列表：头像、名称、最近一条摘要、时间、未读红点；点击联系人整行直接进入气泡聊天，返回后刷新红点。系统通知合并为“预约与交易”“商品审核”等入口，点击看只读通知记录，不提供私信输入。全部已读、消息权限及历史数据保留，不再需要表格选中后点击查看。
