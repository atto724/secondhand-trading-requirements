# 二手交易系统（桌面版）

Python + Tkinter + SQLite，基于实验一需求和实验二 UML 实现。源码均为手写，未使用 GUI 设计工具生成代码。

## 从仓库根目录运行

```powershell
.\code\.venv\Scripts\python.exe .\code\main.py
```

缺少环境时：`python -m venv code/.venv`，再执行 `code/.venv/Scripts/python.exe -m pip install -r code/requirements.txt`。

## 独立演示

```powershell
.\code\.venv\Scripts\python.exe .\code\demo.py
```

演示账号：`demo_admin`、`demo_seller`、`demo_buyer`、`demo_other`，密码均为 `DemoPass123!`。这些账号只存在于 `code/data/demo_gallery`，不修改原来的 `code/data/trading.db`。演示图片采用用户提供的27张商品图，价格和成色是教学样例设定。

演示顺序：买家浏览并预约 → 卖家在“卖家预约”确认 → 卖家登记交付 → 买家确认完成。管理员在管理后台审核待审核示例，也可处理违规、争议、账号授权、更正成交和审计备份。

## 自己的数据

原账号和商品保留。新表和字段通过增量迁移加入。旧空草稿可以在“我的商品”补全或删除，未补全不能提交审核。图片已复制到数据目录，移动原图不会影响已保存副本。

创建首位管理员（密码交互输入，不使用固定默认密码）：

```powershell
.\code\.venv\Scripts\python.exe .\code\manage.py init-admin
```

后续管理员由已有管理员授权。所有管理员操作都重新检查数据库权限。

## 键盘

登录名 Enter 到密码，密码 Enter 登录；缺项时回到缺失字段。商品表单 Enter 到下一项，描述框 Enter 换行，Ctrl+Enter 保存；按钮和快捷键均检查全部必填项。Tab / Shift+Tab 切换焦点。子窗口 Escape 关闭。

## 验证与构建

运行仓库根目录 `build.ps1`，执行单元/集成测试、Black 格式检查、Pylint、wheel 和源码包构建。开发工具安装命令：

```powershell
.\code\.venv\Scripts\python.exe -m pip install -e './code[dev]'
.\build.ps1
```

也可以进入 code 运行 `python -m unittest discover -s tests -v`。构建产物位于 `code/dist`。wheel 需要 Python 和系统 Tk 支持，并非独立 exe。

## 数据与边界

- 付款、物流和线下交付不由程序执行；系统记录预约和交易结果。
- 手机号仅格式校验，未验证手机号归属，未接入真实短信。
- 这是本地教学桌面程序，数据库文件拥有者可直接访问本机文件；角色限制适用于应用服务调用，不构成多租户服务器安全边界。
- 商品与预约联动使用事务；图片文件用异常补偿清理。突然断电可能留下未引用文件，备份保留图片文件以保护历史快照。
- 超时任务和每日自动备份在程序开启时执行；自动备份要求管理员登录。关闭程序期间需部署人员配置外部计划任务，不能据此声称已实现全天备份 SLA。
- UTC 存储事件时间，统计日期按 UTC+8，结束日期包含在区间内。卖家成交率按区间首次发布商品样本计算，当前在售数单列。
- 不声称已通过原需求的 10 万商品 / 100 并发性能指标、浏览器兼容或网络加密部署验收。桌面版不提供浏览器和网络接口。

实验报告必须由学生独立书写；本 README 是程序操作说明，不是实验报告。

新版演示图库位于 `code/data/demo_gallery`：15件带图可浏览商品、1件带图待审核商品、1件带图草稿。旧的 `code/data/demo` 目录保留，不清空已有演示交易。分类采用已确认的10类，启动时迁移旧分类。

商品详情在当前主界面内打开，返回时保留列表筛选和页码。可点击缩略图、上一张/下一张或左右方向键切换图片，Esc返回；长描述支持滚动。7件样例增加详情图，新建演示库共29条图片关联（含待审核和草稿的封面复用）。已有有效预约、非已发布状态或超过5张上限的样例暂缓补图，解除限制后再次启动demo.py会重试，不清空交易数据。

卖家主页：点击商品详情中的卖家框或“进入卖家主页”，可查看公开资料、在售商品和累计成交率。个人主页可编辑昵称/简介/自填所在地；IP属地未获取。商品详情点击“私信卖家 / 咨询商品”进入独立聊天页，Enter换行、Ctrl+Enter发送；在消息中心的“私信会话”查看与回复，点击刷新获取新消息。测试时先买家发送，再退出并登录卖家查看回复；双方必须运行同一数据目录。当前没有跨电脑网络收发功能。

头像：商品详情的卖家框和用户主页均显示头像。个人主页→编辑我的公开资料→更换头像，可选择本地JPEG/PNG图片。没有上传头像时使用内置默认头像，原图损坏或丢失也会回退默认图。

私信以气泡显示：我方右侧浅橙色，对方左侧白色；发送后显示正文并滚动到最新消息。支持头像、时间、长文字换行和加载更早记录；对方新回复可点击“刷新最新消息”读取。已有私信保留。

卖家主页与私信独立：卖家框→公开资料和在售商品；商品详情“私信卖家 / 咨询商品”→独立气泡聊天页，仅显示对方、咨询商品名称与对话。两者均可返回原商品详情。

预约操作：在“我的预约”或“卖家预约”上方按预约状态查看，再选中一条记录；界面只显示该记录当前可用的操作。取消申请发起方显示等待提示，对方显示同意/转人工；已完成或已结束记录仅查看详情。分类旁显示数量，刷新后保留分类；暂无记录可切换其他分类或全部预约。

消息中心：系统通知点击“查看消息”或双击行，在页内显示正文；红点表示仍有未读，读后移除。“全部已读”同时清除当前账号收到的系统通知和私信红点，不删消息。私信仅在对方阅读或主动设为已读后，在我最新发出的一条气泡下显示“已读”；未读不显示文字，发送新消息后隐藏回执。聊天页会自动检查回执，对方新回复仍可用刷新读取。

新版排版：顶部为无框文字导航，选中入口显示橙色下划线；导航名称与功能不变。我的商品、我的预约、卖家预约使用横向商品卡片，包含缩略图、价格、状态及对应行内操作，可滚动查看。我的商品可按商品状态筛选；预约卡片展示预约当时的图片和价格快照。点击卡片按钮直接作用于该条记录，仍受原有角色、状态和预约限制校验。

预约分类已简化为横向“全部、待确认、交易中、取消 / 争议、已完成、已关闭”，各类显示数量。交易中的卡片仍标明待收货/待交付/待确认完成，取消争议仍区分待我处理、等待对方回复和管理员处理中；具体可用操作不因合并分类而改变。

预约详情：点击卡片“预约详情 / 快照”，在当前主界面打开分区详情页，不弹窗。可切换预约时图片，查看商品描述、价格、实际交易进度和授权电话、处理说明；长内容向下滚动。返回保留原预约分类及选择，“刷新详情”重新获取当前状态和电话权限。

主消息中心已改为会话列表：头像、名称、最近一条摘要、时间、未读红点；点击联系人整行直接进入气泡聊天，返回后刷新红点。系统通知合并为“预约与交易”“商品审核”等入口，点击看只读通知记录，不提供私信输入。全部已读、消息权限及历史数据保留，不再需要表格选中后点击查看。

聊天页使用紧凑顶部栏和圆角气泡：本人浅橙、对方白色，宽屏下消息阅读列居中。头像与公开昵称保留；时间只在首次或间隔较久时显示。顶部“刷新”“更早记录”继续可用，底部输入框Enter换行、Ctrl+Enter或橙色“发送”按钮发送。原消息及最新已读规则不变。

账号操作：点击主界面右上圆形头像，展开“退出登录、切换账号、退出应用”。菜单内可辨别当前账号。退出登录和切换账号均清除当前身份和密码输入；切换账号后在登录页输入另一个账号。退出应用仅关闭程序，不删除账号和交易记录。

管理后台新版：以demo_admin登录，审核页默认待审核，可切换状态查看商品卡片；账号授权支持搜索和状态/管理员筛选。各行操作先打开页内确认区，需要原因时必须填写，取消不执行。账号状态和管理员授权分别处理。二级导航采用文字下划线。

商品消息：商品详情→私信卖家，在聊天顶部点击“发送此商品”；对方在会话中看到图片、标题和发送时价格。点击卡片查看当前详情，返回回到对话。打开页面本身不发送；发送商品不清空文字草稿。历史快照保留，商品下架后当前详情可能不可查看。空页面新增新建商品、查看全部、清除筛选、浏览商品等对应入口。

页面保留：切换主导航和管理员二级导航后，搜索、页码、输入内容及打开的详情/聊天保留；主要业务列表返回时更新状态，现有分类/选择/滚动尽量保留。聊天草稿按账号与联系人临时保存在内存，退出对话后重新打开可恢复；发送成功清空，失败保留。退出登录/切换账号/关闭应用后不保留草稿，程序重启不能恢复未发送文字。

流畅性改进：登录显示“正在登录”，校验期间窗口继续响应，重复Enter不重复发起请求。商品图/头像复用有上限缓存，数据未变时复用已有卡片。图片、文字、按钮上的滚轮/触控板手势统一转到所在列表，支持小幅滚动；输入区域保留原生滚动。自动维护延后首次检查并在后台运行。请重启后验收实际触控板，原先页面保留和草稿隔离规则不变。

创建与编辑商品均在“我的商品”页内打开，返回不新增窗口。底部保存/提交/取消固定，正文可滚动；Ctrl+Enter保存，Escape返回，描述Enter仍为换行。切换主导航再回来保留未完成表单；主动返回/取消不保存，保存后返回原分类和滚动位置。

备份验证会检查当前商品图、自定义头像及预约/商品历史/聊天商品卡片中的历史图片，显示去重总数和分类数量；缺失或损坏会列出路径，不能视为验证通过。审计界面每页100条并显示匹配总数，翻页保留原查询范围；导出CSV输出该查询的全部匹配记录，显示实际条数。新日志需点击“查询日志”刷新范围；尚未提交的新关键词不改变已有分页及导出。
